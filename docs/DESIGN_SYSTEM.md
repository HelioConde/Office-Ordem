# Design System — Office Ordem

**Taste Skill:** base #0b1220, superfícies #152033 e #1c2941, divisórias #354660, textos claros; cores de destaque violeta e aqua; espaçamentos padronizados de 4 a 32 px.

**Web Design Guidelines:** navegação semântica, foco visível, labels nos formulários, status com texto e cor, diálogo nativo, confirmações destrutivas, 320px sem overflow da página, suporte a redução de movimento.

**Awesome Design:** dashboard de quatro indicadores, gerenciamento em tabela, filtros, avisos e feedback de ação. Os cards e controles estão preparados para mobile.

**Image to Code:** redesign dos componentes HTML/CSS do sistema de serviços, sem biblioteca visual ou imagens externas. O código-fonte React histórico não existe nesta cópia; seu build foi preservado no legacy.html.

**Segurança:** entradas inseridas via textContent; backup JSON limitado a 1 MB e 250 registros, com validação de formato; valores exportados para CSV são neutralizados contra fórmula. Todo armazenamento é local e não constitui serviço multiusuário.
