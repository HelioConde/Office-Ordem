# Office Ordem — Protótipo web para ordens de serviço

**Interface experimental para criação e organização de ordens de serviço.**

## Estado do repositório

A raiz contém **arquivos estáticos compilados de um aplicativo React**, incluindo `index.html`, `static/`, `asset-manifest.json` e `manifest.json`.

> O código-fonte React e a configuração de build não estão disponíveis na raiz desta versão. Por isso, este repositório deve ser tratado como um **snapshot de distribuição**, não como um projeto pronto para desenvolvimento via `npm install`.

## Visualizar

Sirva os arquivos por um servidor HTTP estático e abra a página inicial. Como os caminhos dos assets compilados usam `/static`, sirva a aplicação na **raiz** do servidor para evitar arquivos ausentes.
